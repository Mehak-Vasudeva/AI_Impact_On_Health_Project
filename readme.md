# 🩺 AI Impact on Health

An interactive data analysis and visualization project built using Python and Streamlit to study the impact of AI health tools on users' health, lifestyle, and satisfaction.

## 🎯 Objective

The main objective is to analyze health scores before and after AI usage and identify patterns related to AI tool usage, exercise, BMI, age, and user satisfaction.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## 📊 Features

- 🏠 Interactive Health Dashboard
- 🔍 Dataset Explorer
- 📈 Interactive Visualizations
- 💡 Key Insights
- 🔥 Correlation Heatmap
- ⭐ Satisfaction Analysis
- 🤖 AI Tool Usage Analysis
